# Legacy Teacher/Student Model Pair Diagrams

This folder contains SVG structure diagrams for the pre-v2 hardware-specific
teacher and distilled student workflow. These diagrams are retained only for
historical reference.

Do not use these configs or run IDs for new v2 training. Use
`src/perfseer-optimized/configs/train_hardware_teacher/v2_teacher.yaml` and
`src/perfseer-optimized/configs/train_deploy_model/v2_student.yaml` instead.

Source configs:

- Teacher: `src/perfseer-optimized/configs/train_hardware_teacher/large_teacher.yaml`
- Default student: `src/perfseer-optimized/configs/train_deploy_model/distill_student_128.yaml`
- Optional wider student: `src/perfseer-optimized/configs/train_deploy_model/distill_student_192.yaml`
- Runner at the time: `scripts/run_hardware_distill_flow.py`

SVG files:

- `teacher_student_distillation_flow.svg`: end-to-end teacher-to-student flow.
- `hardware_large_teacher_structure.svg`: detailed teacher structure.
- `hardware_distill_student_128_structure.svg`: detailed default student structure.

The legacy pair generated by the old runner was:

- `hardware_large_teacher_<hardware-id>`
- `hardware_distill_student_128_<hardware-id>`

The 192-wide student uses the same student structure with `hidden=192` and
`head_hidden=192`.
