# PerfSeer v3.2 student weights

`predictor_v3.2_student.pt` is the sole deployable checkpoint in this package.
It is the verified 11.6 MB V3.2 student export, selected at epoch 12. `validation-summary.json` records its Ground Truth validation metrics.

The provenance-matched teacher checkpoint is stored at `../.cache/teacher_v3.2_epoch26.pt` to keep large model weights in the package cache.
